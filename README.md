# LearnAutomation

A collection of Java logic-building exercises — classic DSA and programming problems
implemented from scratch as part of daily problem-solving practice.

## Topics Covered

- Strings: anagrams, palindromes, permutations, reversal variants, character/word counts
- Arrays: rotation, leaders, merge, move zeros, missing number, second largest, pair sum
- Numbers: prime, factorial, Armstrong, FizzBuzz, binary conversion, random numbers
- Concurrency: odd/even printing with threads
- Design: singleton pattern

## Requirements

- JDK 8 or higher

## Running a file

Compile and run any single program directly:

    javac src/Palindrome.java
    java -cp src Palindrome

## Layout

- src/  — one self-contained .java file per exercise, each with its own main() method
